# 好好想想

好好想想把聊天、日常记录和生活提醒放在一起。可以和兔兔聊聊每天发生的事，也可以记录待办、便签、碎碎念、倒数日和纪念日，分别设置三餐提醒。

## 源码

本仓库提供整理后的 iOS 源码，包括网页界面、Tauri 桥接、原生本地通知、WeatherKit 接入、实时活动和本机聊天推理接口。

- [iOS 源码](ios/)
