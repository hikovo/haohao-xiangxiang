# 好好想想

和兔兔聊聊天，记下每天的小事。

好好想想是一款陪你聊天、记录日常和安排生活提醒的应用。忙完一天，可以回来摸摸兔兔、陪它玩一会儿，也把今天发生的事情慢慢讲给它听。

## 回来和兔兔待一会儿

在小家里摸摸兔兔，陪它玩一会儿。让兔兔跟着你逛逛，也在灵动岛上陪着你。你可以调整兔兔的大小，选择自己喜欢的陪伴方式。

## 今天发生的事，都可以聊聊

遇到开心的事情，或是心里有些话想说，都可以打开“说说话”，慢慢讲给兔兔听。下载聊天资源后，就可以在本机开始聊天。头像、聊天背景和气泡也可以换成自己喜欢的样子。

## 把想做的事和想记住的日子写下来

用待办安排每天的事情，用便签和碎碎念留下当时的想法。倒数日帮你期待将来的相聚，纪念日帮你珍藏一起走过的日子。想专心做一件事时，也可以打开专注倒计时，让兔兔陪你完成。

## 每天的小事，也有人惦记

早餐、午餐和晚餐可以分别设置提醒时间，天气小叮咛会带来天气信息和出门提示。再为每天的小约定安排一个时间，和兔兔一起把日子慢慢过好。
