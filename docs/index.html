好好想想使用帮助

这里收好了一些常用功能的操作方法。有想问的事情，也可以写信给我们。

怎样开始聊天？

打开“说说话”，按照消息中的提示下载聊天资源；也可以进入聊天设置管理资源。下载完成后切换到聊天模式，就可以把今天发生的事情慢慢讲给兔兔听。首次下载时，请保持网络连接，并为设备预留足够空间。

怎样设置生活提醒？

进入“我的”，打开对应的提醒设置，选好时间和提醒方式后保存。早餐、午餐和晚餐可以分别设置。想在锁屏时收到提醒，可以在系统设置中开启好好想想的通知，并按需要调整声音和专注模式。

怎样保存每天的小事？

在“备忘录”中添加待办、便签、碎碎念、倒数日或纪念日，再点开条目编辑内容。需要留存副本时，可以使用应用中的导出功能，选择合适的位置保存。

怎样换成喜欢的样子？

在聊天外观设置中更换头像、聊天背景和气泡。在“我的”页面，可以调整兔兔的大小、陪伴显示和提醒设置，让它按你喜欢的方式陪着你。

遇到问题怎样联系？

欢迎发送邮件至 hikodesuu@gmail.com。请写下设备型号、iOS 版本、App 版本，以及出现问题前的操作；有截图时可以一起附上，并先遮住其中的个人信息。我们会根据这些信息查看问题。
